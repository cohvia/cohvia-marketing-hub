# Project Memory

## Core
Cohvia = AI-native Customer Success platform for B2B SaaS. Dark mode site.
Figtree font everywhere. Primary teal #1a9e8f. Midnight bg #0B0E17, navy cards #131827.
Brand gradient: #1B3A4F → #2A7B8A → #6ECFC0 (to top right). Use on CTAs & hero, NOT on text links.
Brand: calm authority, instant clarity. "Put the human back into Customer Success."
No stock photos, no serif fonts. Use white logo on dark backgrounds.
Avoid: "single source of truth", "finally clear", generic SaaS buzzwords.
